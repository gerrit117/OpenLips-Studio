# Generation provenance

Tool: built-in `image_gen.imagegen`, not CLI/API fallback. No external brand
reference was supplied. Subsequent images reference the generated OpenLips
Studio design to retain the note-bar motif and wordmark.

## Base wordmark

Use case: logo-brand. Create one polished production-ready horizontal logo for
the open-source karaoke song editor named exactly "OpenLips Studio". Minimal
flat identity, quiet, precise, friendly, mature. One compact custom symbol at
left made of exactly three solid horizontal karaoke note bars staggered in
pitch, stepping from bottom left to upper right, with subtly rounded ends.
Muted teal #319F98. Text exactly "OpenLips Studio": clean restrained
medium-weight humanist sans-serif for OpenLips and regular Studio, same
typeface, one line. Natural spacing, conventional mixed case, no playful or
sci-fi letters. No gradients, shadows, perspective, glow, glossy surfaces,
textures, lips illustration, microphones, clefs, decorative swooshes or mockups.
An intermediate transparency/flatness edit was generated but not selected for
this delivered opaque banner set.

## Final dark icon

Produce one DARK MODE app icon derived strictly from the three ascending
horizontal note bars at the left of the logo. Remove all text. Square canvas.
Solid charcoal #20262C background, no border, rounded outer tile or mockup.
Center the same three horizontal capsule-shaped bars stepping bottom-left to
top-right, same distinctive lengths and offsets. Symbol approximately 65 percent
of width and 36 percent of height, optically centered. Solid muted teal #319F98.
Clean flat vector-style drawing, antialiasing only at edges. No grain, texture,
light source, gradient, shadow, depth, bevel, glass, outlines or metallic effects.
Exactly three separated bars, no other shapes, letters or captions. Clear at 32px.

## Final light icon

Create the LIGHT MODE companion of the dark icon. Change only the background
to solid white #FFFFFF and all three bars to uniform muted teal #319F98.
Preserve bar lengths, offsets, spacing, size and centering; same square layout.

No shadows, gradients, glow, highlights, grain, depth, texture, outlines or

The tool did not obey exact dimension/color/flatness instructions perfectly.
Actual selected PNG dimensions are documented in README.md; these are design
drafts, not a claim of deterministic two-color vector output.
