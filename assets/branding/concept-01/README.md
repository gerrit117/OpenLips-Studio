# OpenLips Studio: Logoentwurf 01

Erster zusammengehoeriger Logo-/Iconentwurf, noch nicht in die App oder die
Haupt-README eingebaut. Keine Spieldateien oder vorhandenen Markenlogos kopiert.

| Datei | Verwendung | PNG-Abmessungen |
| --- | --- | --- |
| logo-light.png | Wortmarke auf hellem Hintergrund | 2172 x 724 |
| logo-dark.png | Wortmarke auf dunklem Hintergrund | 2172 x 724 |
| icon-light.png | Symbol auf hellem Hintergrund | 1254 x 1254 |
| icon-dark.png | Symbol auf dunklem Hintergrund | 1254 x 1254 |

Drei versetzte Karaoke-Notenbalken bilden das gemeinsame Zeichen. Graphit,
Weiss und ein gedeckter Teal-Akzent; keine 3-D-Elemente oder verspielte Schrift.
Die Bilder wurden mit dem eingebauten image_gen-Werkzeug generiert. Es sind
Rasterentwuerfe, keine finalen Vektormaster und keine ICO-/ICNS-Dateien.
Die generierte Schrift hat keinen verifizierten Fontnamen. Eine saubere
Vektorumsetzung und finale kleine Icongroessen folgen nach Designfreigabe.

Die Bildgenerierung hat trotz Flat-Vorgabe leichte Ton-/Texturvariationen
beibehalten. Fuer einen endgueltigen streng zweifarbigen Vektormaster muessen
diese entfernt werden; die Entwuerfe werden nicht als pixelgenau flache
Produktionsdateien ausgegeben.

Die verwendeten Prompt-Spezifikationen stehen in [prompts.md](prompts.md).
