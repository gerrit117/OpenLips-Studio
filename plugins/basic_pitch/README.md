# Basic Pitch for OpenLips Studio

The `.opl` adapter is preinstalled with Studio. Its platform-specific ONNX
worker is bundled separately, not downloaded or installed by this package.
Installing the same ID twice is unnecessary and is rejected by the manager.

The independent OpenLips adapter code is GPL-3.0-or-later. Basic Pitch and its
model are Copyright 2022 Spotify AB, Apache-2.0. See the upstream authors,
documentation and license at https://github.com/spotify/basic-pitch.
No Spotify account, API key or audio upload is involved.
